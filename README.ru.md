# HUD Workshop

<img src="images/icon.png" alt="HUD Workshop" width="96" height="96">

[English](README.md) · **Русский**

Редактор интерфейса FFXIV прямо в игре. Позволяет перемещать и выравнивать элементы, менять их свойства и обмениваться раскладками.

## Установка и обновление

Требуются Windows, Dalamud **15.0.3.4 / API 15** и FFXIV **2026.09.01.0000.0000**. Penumbra не требуется. Интерфейс аддона на русском языке.

1. Откройте `/xlsettings` → Experimental → Custom Plugin Repositories.
2. Добавьте адрес:

   ```text
   https://raw.githubusercontent.com/GodRayine/HUD-Workshop/main/repo.json
   ```

3. Откройте `/xlplugins`, обновите список и установите **HUD Workshop**.
4. Введите `/hudworkshop`, чтобы открыть редактор.

Обновления устанавливаются через `/xlplugins`. [Архив версии 1.1.1](https://github.com/GodRayine/HUD-Workshop/releases/tag/v1.1.1) доступен на странице релиза.

Если использовали dev-сборку, сначала сохраните HUD, отключите её и удалите запись из Dev Plugin Locations. Не удаляйте настройки HudEditor и не запускайте две копии одновременно.

## Перемещение и свойства

- Выберите рамку элемента мышью и перетащите её. Свойства выбранного элемента появляются в окне редактора; его также можно выбрать через список.
- Включите **Привязка к сетке** и **Приклеивать панели**, чтобы удобнее располагать элементы. **Показывать сетку** управляет отображением сетки.
- Удерживайте **Alt**, чтобы временно отключить привязки.
- Меняйте положение, масштаб и включение элемента в свойствах. Для обычных панелей способностей также доступна форма панели.
- **Элементы других режимов** позволяет показать доступные рамки неактивных элементов.

## Несколько элементов

**Shift + клик** добавляет элемент к выделению или убирает его. Используйте выделение рамкой и группы для совместного редактирования. Перемещение выделенного набора сохраняет взаимное расположение элементов. В секции выделения доступны выравнивание, равные интервалы и **Выровнять по сетке**.

## Сохранение и отмена

- **Отменить шаг** и **Повторить** перемещают по истории изменений.
- **Отменить всё** возвращает исходное состояние предпросмотра.
- **Сохранить HUD** сохраняет изменения.
- Закрытие редактора отменяет несохранённые изменения. **Esc** отменяет активное перетаскивание, а в остальных случаях закрывает окно.

Если появляется **Повторить отмену**, нажмите её для повторной попытки восстановления. До завершения восстановления новые изменения недоступны.

## Экспорт и импорт раскладки

Для экспорта нажмите **Экспортировать и скопировать** в секции обмена раскладкой и передайте полученную строку другому игроку.

Для импорта:

1. Скопируйте строку раскладки и нажмите **Вставить из буфера** либо вставьте её в текстовое поле.
2. При необходимости включите **Подстроить координаты под разрешение** — изменятся координаты, но не масштаб.
3. Нажмите **Проверить строку** и просмотрите результат проверки.
4. Нажмите **Применить предпросмотр**, оцените расположение и нажмите **Сохранить HUD**. Для отказа используйте отмену.

Строка переносит поддерживаемые положения, масштабы, видимость и форму элементов. Назначения способностей, группы редактора и настройки общего/раздельного режима цели и статусов не переносятся. Неподдерживаемые элементы пропускаются.

## Особенности использования

Редактирование приостанавливается во время боя и переходов. Крестовые панели не поддерживаются. Скрытие чата действует, пока аддон загружен. Если все элементы статусов скрыты и их режим ещё не определён, редактор предполагает раздельный режим.

Если окно не открывается, проверьте, включён ли HUD Workshop в `/xlplugins` и совпадают ли версии игры и Dalamud с указанными выше.
