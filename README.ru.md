# HUD Workshop

<img src="images/icon.png" alt="Иконка раскладки HUD Workshop" width="96" height="96">

[English](README.md) · **Русский**

Редактор HUD для FFXIV / Dalamud прямо в игре: привязки, групповое редактирование и свойства сразу при выборе элемента. Интерфейс плагина на русском языке; README доступен на двух языках. Penumbra не требуется.

## Статус и совместимость

В этой ветке подготовлена **1.1.0.0 для ревью**. Она ещё не опубликована и не принята в официальный каталог Dalamud. Публичный сторонний каталог продолжает устанавливать [1.0.0](https://github.com/GodRayine/HUD-Workshop/releases/tag/v1.0.0).

Требуются Windows, **Dalamud 15.0.3.4 (API 15)** и **FFXIV 2026.09.01.0000.0000**. Нативные структуры зависят от версии. Плагин отказывается загружаться с другой версией Dalamud; снятие ограничения не обеспечивает совместимость.

## Установка опубликованной версии

В `/xlsettings` → Experimental → Custom Plugin Repositories добавьте:

```text
https://raw.githubusercontent.com/GodRayine/HUD-Workshop/main/repo.json
```

Откройте `/xlplugins`, обновите список и установите **HUD Workshop**. Команда открытия — `/hudworkshop`. При переходе с dev-сборки сначала сохраните HUD, отключите её и удалите запись из Dev Plugin Locations. Сохраните конфигурацию HudEditor и запускайте только одну копию.

## Возможности

- Сетка, приклеивание границ, выравнивание и равные интервалы.
- Множественное выделение, сохранённые группы и совместное перемещение.
- Положение, масштаб, форма обычных панелей и включение элементов.
- Рамки поддерживаемых неактивных элементов, основной и вынесенный чат.
- Отмена/повтор операций и отмена несохранённого предпросмотра.
- Обмен раскладкой строкой `HUDW1` с проверкой и предпросмотром перед сохранением.

Выберите элемент, чтобы изменить его свойства. **Shift + клик** меняет выделение; **Alt** временно отключает привязки. **Сохранить HUD** сохраняет раскладку. Закрытие инспектора отменяет несохранённые изменения. Escape должен сначала отменять активное перетаскивание, а в остальных случаях закрывать инспектор; сценарий с перетаскиванием ещё требует итоговой проверки в игре.

Строка раскладки переносит поддерживаемые положения, масштабы, видимость и настройки формы. Она не содержит сообщений чата, идентификаторов персонажа, назначений способностей, групп редактора и переключателей общего/раздельного режима цели и статусов. Неподдерживаемые элементы пропускаются. Адаптация под разрешение по желанию меняет координаты, но не масштаб.

## Ограничения и проверки

Крестовые панели не поддерживаются. Остальные профессии и специальные режимы не прошли полную проверку. Если все статусы скрыты и режим ещё не наблюдался, предполагается раздельный режим. Скрытие чата поддерживается, пока работает плагин. Во время боя и переходов редактирование приостанавливается.

Release-сборка 1.1 и **72 автоматические проверки** проходят. Они проверяют геометрию, формат строки и управляемые сценарии отказа сохранения/восстановления, но не нативное сохранение игры. Владелец подтвердил открытие, закрытие по Escape, повторное открытие и исправленное положение кнопок заголовка. Ещё нужны итоговые проверки сохранения с перезапуском, импорта через UI, прерываний, частичного восстановления и чистой установки/обновления. Подробности — в [матрице проверок](review/TEST-MATRIX.md) и [заметках готовности](review/READINESS.md).

## Сборка и упаковка

Нужны **.NET SDK 10.0.100**, PowerShell 7 и соответствующие библиотеки Dalamud. Версии зависимостей и NuGet lockfile включены в репозиторий.

```powershell
./build.ps1 -DotnetPath 'C:/path/to/dotnet.exe' -DalamudPath 'C:/path/to/Hooks/15.0.3.4'
dotnet run --project tests/GeometryTests.csproj --configuration Release
./package-release.ps1 -DotnetPath 'C:/path/to/dotnet.exe' -DalamudPath 'C:/path/to/Hooks/15.0.3.4'
```

Упаковка восстанавливает зависимости в locked mode, собирает проект, запускает тесты, проверяет соответствие манифеста и DLL, состав ZIP и SHA-256. Результат — `release/<версия>/`, версия берётся из проекта. Архив исходников содержит оба README, лицензии и материалы ревью. Скрипт ничего не загружает в сеть и не меняет опубликованный каталог. См. [инструкцию выпуска](docs/RELEASE.md).
