# Проверки перед заявкой

Каждая строка получает результат, дату, сборку и фактический сценарий. Не считать наличие кода доказательством работоспособности.

| Сценарий | Статус |
|---|---|
| Чистая Release-сборка1.1 | Пройдена |
| 72 автоматических проверок | Пройдены |
| WindowSystem: открыть/закрыть/Esc/повторно открыть | Подтверждено пользователем на локальной1.1 до последних правок отмены |
| Кнопки сворачивания и настроек в заголовке | Подтверждено пользователем после исправления отступов |
| Esc во время drag отменяет только drag | Не проверено |
| X/Y, scale, shape, enable: mixed undo/redo/cancel | Нужна регрессия1.1 |
| Строка export/import, no-op, skip, ошибка формата | Формат проверен; UI не проверен |
| Save→закрыть→открыть→перезапуск игры | Не проверено на1.1 |
| Частичный отказ записи/rollback | Проверена только управляемая граница |
| Бой, переход, смена слота/персонажа во время preview | Не завершено |
| Обычный/раздельный target, скрытые статусы | Нужна проверка крайних случаев |
| Основной/вынесенный чат, unload/reload | Нужна регрессия1.1 |
| Другие профессии/спецрежимы и offline→loaded | Не проверено |
| Установка и обновление через каталог | Не проверено |

Владелец разрешил повторные проверки сохранения и остальных профессий. Переключение классов/режимов выполнять вне боя с сохранением исходной раскладки; не восстанавливать старые бэкапы поверх новой раскладки.
